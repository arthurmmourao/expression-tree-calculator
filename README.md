# Expression Tree Calculator in C

Implementação de uma estrutura de dados de Árvore Binária para análise e avaliação de expressões matemáticas (Parsing & Evaluation), simulando a lógica de compiladores.

## 🚀 O que o projeto faz
- Constrói e manipula Árvores de Expressão em memória.
- Realiza travessia e avaliação recursiva de nós (operandos e operadores).
- Respeita a precedência matemática hierárquica estruturada nos nós.

## 🛠️ Tecnologias
- Linguagem C
- Alocação Dinâmica de Memória (`malloc`)
- Estruturas de Dados (Árvores Binárias)

## ⚙️ Como Executar
```bash
gcc main.c -o calculator
./calculator
